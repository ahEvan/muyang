02 · About

关于沐阳

一支由老师指导、学生组成的朋辈心理支持团队，自 2016 年起持续陪伴在校园里。

协会简介

沐阳心理协会（简称“沐阳心协”），成立于2016年，协会位于上海立信会计金融学院，是为学生提供健康交流平台和心理卫生服务与帮助，唤起当代大学生对心理健康的重视，守护大学生快乐成长的校级组织。公司核心团队由经验丰富的老师、热情的学长学姐组成，共分为三个部门——办公室部、新媒体部和实践部。

我们的宗旨是服务学生、关注学生、守护学生心理健康——创造更和谐美好的校园环境。我们倡导“热情、冷静、自信、耐心、坦诚、好学”的工作态度，以及助人为乐、快乐成长的理念。我们传播心理健康知识，为学生提供健康交流平台和心理卫生服务与帮助，唤起当代大学生对心理健康的重视，守护大学生快乐成长。

名称寓意

沐阳

“沐阳”取自“沐浴阳光，向阳而生”，寓意协会以温暖、陪伴、成长为根本，致力于让每一颗心灵在理解与接纳中汲取力量、向光而行。

使命

普及心理健康知识，搭建健康交流平台，提供心理卫生服务与帮助，唤起当代大学生对心理健康的重视，守护学生快乐成长，助力创造更和谐美好的校园环境。

愿景

成为上海立信会计金融学院学生值得信赖的朋辈心理支持与心理健康宣传伙伴，让“沐阳”成为温暖、专业、可信赖的校园心理服务品牌。

核心价值观

  • 沐心——以热情、坦诚对待每一位同学，尊重差异、接纳情绪，营造安全信任的交流空间；
  • 倾听——以耐心、冷静开展朋辈沟通，不评判、不贴标签，关注学生真实需求；
  • 守密——严格遵守心理服务伦理与保密原则，保护学生隐私和信息安全；
  • 专业——在老师指导下规范开展预约接待、宣传与活动，持续学习、提升助人能力；
  • 共进——协会成员、朋辈、老师与各部门共同成长，助人自助、快乐成长。

承诺

接待有温度、服务有边界、宣传有依据、隐私有保护、活动有反馈。值班接待主动耐心，尊重来访者意愿；朋辈支持不替代专业咨询，发现风险及时转介；心理健康知识来源可靠、口径可溯源，不夸大不误导；咨询预约与个人信息严格保密，资料规范管理；活动前中后期宣传总结闭环，收集同学反馈持续改进。

04 · Departments

部门工作

三个部门各司其职、彼此配合，共同支撑协会的日常运转与活动落地。

办公室部

工作内容

  1. 每周值班并接待心理咨询预约者
  2. 协调心理咨询工作的相关安排
  3. 宣传、总结组织举办的活动，撰写活动推文
  4. 撰写每周心报

能力要求

  1. 上海立信会计金融学院（文翔路校区）在校学生
  2. 有同理心和较强的共情能力
  3. 愿意与他人进行交流，有良好的沟通能力
  4. 需具备随机应变的能力，能够沉稳地面对突发状况
  5. 认真踏实、做事细心、有责任感、愿意在课余时间协助咨询师的工作
  6. 热爱写作，有较好的写作能力和语言组织能力，并对心理学有一定的兴趣

成果收获

  1. 如何接待心理咨询来访者
  2. 提高自己的语言组织能力、表达能力
  3. 独立撰写一篇优秀的推文
  4. 如何更好地与他人沟通
  5. 如何与其他部门进行有效对接
  6. 一个温馨的创作者小家

新媒体部

工作内容

  1. 公众号推文排版与运营（如“心心漫漫”心理漫画专题、每周心报专题等专题）
  2. 宣传海报和物料设计与制作
  3. 线下活动的拍摄

能力要求

  1. 上海立信会计金融学院（文翔路校区）在校学生
  2. 责任心强，工作认真负责，耐心细致，有团队意识
  3. 拥有创造力和想象力，有独特的idea
  4. 对公众号推文排版、运营，海报、物料设计以及心理知识感兴趣，愿意为组织活动提供一些时间
  5. 有一定摄影、视频剪辑或是绘画基础（非必要）

成果收获

  1. 进行推文排版、海报制作及各类物料周边的设计（易拉宝、明信片、挂件等）
  2. 绘画软件、相机与视频剪辑软件的基本使用方法，提高新媒体技术
  3. 如何与其他部门有效合作
  4. 一个温馨的创作者小家

  4. 在接受任务后能独立思考、创新，拥有解决问题的能力，及时高效完成任务
  5. 有大局观，执行力满分，需自行对于工作的轻重缓急加以判断并做出快速反应
  6. 具备良好的性格，能融入团队参与活动之中

成果收获

  1. 独立完成一整份策划案的能力
  2. 学习推行一个活动的完整流程、完善自己的细节把控力
  3. 提高与多人的沟通能力与效率
  4. 累积到多次外出实践活动的经验
